Termos de uso

Minuta para revisão · 26 de setembro de 2026

Este documento é uma minuta acadêmica. Antes de publicar o sistema para uso real, revise-o com orientação jurídica e informe os dados do responsável pelo projeto.

1. Sobre a plataforma

O Questio PFC é um protótipo acadêmico de sistema de aprendizagem adaptativa, pensado para oferecer atividades em ritmos e formatos diversos. A plataforma não substitui acompanhamento educacional, clínico ou terapêutico.

2. Conta e acesso

Para criar uma conta, informe nome, e-mail e uma senha pessoal. Você é responsável por manter sua senha em sigilo e por avisar o responsável pelo sistema caso perceba acesso não autorizado. Não use a plataforma para enviar dados de saúde ou informações que não sejam necessárias ao protótipo.

3. Uso responsável

Use o sistema de modo respeitoso e apenas para os fins propostos. O protótipo pode ficar indisponível durante manutenção e seus recursos podem mudar durante o desenvolvimento acadêmico.

4. Endereços

A consulta de CEP é atendida pelo serviço público ViaCEP. Ao fazer uma consulta, o CEP informado é enviado ao ViaCEP para localizar o endereço. O Questio PFC não salva o CEP nem o endereço consultado.

5. Dados e encerramento

O tratamento de dados é descrito na Política de privacidade. Para solicitar correção ou exclusão da conta neste protótipo, contate o responsável pelo projeto. A implantação real deve disponibilizar um canal de contato funcional.

6. Atualizações

Os termos podem ser atualizados para refletir mudanças no projeto. A versão vigente e a data de atualização devem ser indicadas nesta página.
